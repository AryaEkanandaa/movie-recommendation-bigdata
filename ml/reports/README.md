# Reports

Folder ini berisi output ringkasan yang aman dibuka untuk analisis, laporan, dan presentasi.

## Struktur

- `data/`: ringkasan dataset final.
- `eda_figures/`: grafik EDA yang sudah dipisahkan per konteks.
- `preprocessing/`: ringkasan preprocessing.
- `modelling/`: hasil training, evaluasi, dan perbandingan model rekomendasi.

File dataset besar dan model tidak disimpan di sini. Dataset besar ada di `ml/data/` dan model ada di `ml/models/`, keduanya tidak di-push ke GitHub.
