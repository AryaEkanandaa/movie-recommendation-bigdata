# EDA Figures

Folder ini adalah versi terorganisir dari grafik EDA. Subfolder dipisahkan berdasarkan konteks analisis.

## Struktur

- `distributions/`: distribusi nilai numerik dan kategori umum.
- `time/`: grafik berdasarkan tahun, dekade, dan bulan rilis.
- `top_entities/`: genre, cast, director, keyword, bahasa, dan negara teratas.
- `relationships/`: hubungan antar metrik, seperti budget vs revenue.
- `data_quality/`: missing values dan kelengkapan metadata.
